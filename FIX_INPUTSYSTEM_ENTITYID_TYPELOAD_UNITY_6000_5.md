# Unity 6000.5.9f1 — Input System recovery v1.4

## Errors this fixes

- `CS0619: EntityId.implicit operator int(EntityId) is obsolete`
- `TypeLoadException: Could not load type UnityEngine.InputSystem.InputActionAsset`
- Safe Mode caused by Input System editor-package compilation

## Root cause

Input System 1.18.x is not sufficiently compatible with the API deprecations enforced by this Unity 6000.5 editor.

Input System 1.19.0 changed `PlayerInputEditor` to store the action asset id as `EntityId`.
Input System 1.20.0 is the current release and supports Unity 6000.0+.

The `TypeLoadException` indicates that Unity has stale compiled/package assemblies from the previous Input System version in the project's generated `Library` cache.

## Correct recovery procedure

IMPORTANT: Unity must be CLOSED before deleting cache directories.

1. Close Unity completely.
2. Replace the project's `Packages/manifest.json` with the v1.4 file.
3. Verify:
   `"com.unity.inputsystem": "1.20.0"`
4. Delete:
   - `Library/`
   - `Temp/` if present
   - `obj/` if present
   - `Packages/packages-lock.json` if present
5. Do NOT delete:
   - `Assets/`
   - `Packages/manifest.json`
   - `ProjectSettings/`
6. Reopen the project in Unity 6000.5.9f1.
7. Let Unity finish Package Manager resolution and the complete Library reimport.
8. In the Console, confirm there are no red errors from:
   `Library/PackageCache/com.unity.inputsystem@...`
9. Exit Safe Mode only after compilation succeeds.

## Input Manager warning

This warning is not the reason Safe Mode starts.

After the project compiles:
- Edit > Project Settings > Player > Other Settings > Configuration
- Active Input Handling = `Input System Package (New)`
- Restart Unity once.

The game code in v1.2+ already uses the new Input System only.

## Dynamic Batching warning

Also not a compile error.

After compilation:
- Edit > Project Settings > Player > Other Settings > Rendering
- Disable `Dynamic Batching`.

The current project is primarily Canvas/uGUI and 2D art, so disabling this deprecated mesh batching option is appropriate.

## If Unity still shows an older package

Close Unity again and verify `Packages/manifest.json`.
Then delete `Library` and `Packages/packages-lock.json` again.

Do not patch files in `Library/PackageCache`; they are regenerated by Package Manager.
