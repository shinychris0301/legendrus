This milestone makes Chapter 1 post-victory story presentation deterministic,
marks the four major story milestones, and adds localized victory and failure
character reactions for every released level.

Open this folder directly in Unity 6000.5.9f1. Run:

1. `Legends of Rus > Validate Commercial Vertical Slice`
2. `Legends of Rus > Tests > Run v1.13 Step 2 Self-Tests`
3. EditMode and PlayMode tests from Unity Test Runner

`Assets/LegendsOfRus/Documentation/V1_13_STEP02_STORY_MILESTONES_CHARACTER_REACTIONS.md`.
