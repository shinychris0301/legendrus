# v1.17 Step 5 Compile Hotfix 02 — Addressables / EntityId

## Cause

Unity 6000.5 makes `UnityEngine.Object.GetInstanceID()` a compile error. The original
Step 5 package pin (`com.unity.addressables` 2.7.6) still contains calls to that API in
ResourceManager code, causing CS0619 inside `Library/PackageCache`.

## Fix

The Step 5 package pin is upgraded to `com.unity.addressables` 2.8.1. That release
contains Unity 6000.3+ compatibility branches using `Object.GetEntityId()` in the two
failing ResourceManager paths.

Do not edit `Library/PackageCache` manually; it is generated by Unity Package Manager.
After applying this hotfix, close Unity, remove the cached 2.7.6 Addressables package
folder if it remains, and reopen the project so Package Manager resolves 2.8.1.

Remote catalogs/content, catalog updates, economy, commercial activation, and production
publishing gates remain disabled.
