# Step 11.2 Approved Reference Staging

Place only explicitly review-ready **941×1672 PNGs** here using the canonical `ScreenId` filename, for example `Pause.png` or `ChapterComplete.png`.

Staging is **not approval**. The Unity tool will copy a staged image into `Assets/LegendsOfRus/Art/ReferenceOnly/ApprovedScreens` only when the exact ScreenId is also listed in `USER_APPROVED_REFERENCE_PAGES.txt` and you confirm the interactive promotion dialog.

The tool refuses to overwrite any already-approved reference.
