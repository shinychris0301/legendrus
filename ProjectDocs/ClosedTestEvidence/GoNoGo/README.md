# v1.18 Step 6 — Closed-test go/no-go evidence

This folder is an evidence staging area only. Do not store Play account credentials, tester email addresses, Google Group membership, keystore paths/passwords, device identifiers, or free-form logs here.

The Step 6 tooling consumes only privacy-minimal evidence: candidate/frozen AAB hashes, version values, release-state enums, aggregate tester counts/days, blocking issue counts, and reviewed approval flags.

The source candidate intentionally contains no actual Play Console upload evidence and performs no network or publishing action.
