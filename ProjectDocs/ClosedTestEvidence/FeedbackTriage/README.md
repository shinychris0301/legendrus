# Closed-test feedback triage evidence

Use stable non-identifying issue IDs such as `LOR-CT-0001` and the fixed category/severity/disposition fields from `LegendsOfRus.ClosedTestExecutionCore`.

Do not retain tester names, email addresses, Google Group membership, raw chat transcripts, device identifiers, Play Console credentials, keystore credentials, or unrestricted free-form tester text in the candidate-freeze / production-access evidence set.

Raw feedback may be handled in an approved external workflow; only the privacy-minimal triage result belongs in this project evidence boundary.
