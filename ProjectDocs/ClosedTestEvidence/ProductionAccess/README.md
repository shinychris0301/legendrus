# Production access evidence

This directory is for reviewed evidence supporting a production-access application. The source package contains templates only.

For applicable personal developer accounts created after 13 November 2023, verify the Play Console requirement of at least 12 testers continuously opted in for at least 14 days before applying. The project does not assume account type or eligibility.

The application evidence must separately confirm review of the testing process, tester feedback, changes made as a result of testing, and production readiness. Submission remains an explicit operator authorization.
