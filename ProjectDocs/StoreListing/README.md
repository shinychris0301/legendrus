# Google Play Store Listing Staging — v1.18 Step 3

This folder is a release-preparation staging area only.

`draft_metadata.json` contains non-approved store metadata. Final approved preview
assets, when they exist, belong under `FinalAssets/` and must pass the Step 3
validator before the source activation flags can be reviewed.

Do not copy `Assets/LegendsOfRus/Art/ReferenceOnly/ApprovedScreens` or
`Resources/DesignScreens` into `FinalAssets` as substitutes for captured runtime
screenshots. The approved design screens remain reference art, not release evidence.

Current Step 3 deliberately ships no final store icon, feature graphic, screenshots,
or Play publishing authorization.
