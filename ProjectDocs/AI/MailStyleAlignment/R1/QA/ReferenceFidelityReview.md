Compared both originals with actual Unity inbox and letter captures. This initial native UI reproduces the main hierarchy and source artwork, but is not a pixel-exact replica.

| Area | Match / remaining difference |
|---|---|
| Russian title | Original lettering/plaque pixels. English uses live selected typeface on a cleared face. |
| Account header | Reuses the approved header with real saved values. Font weight, portrait and framing differ from these references. |
| Message list | Five original sender icons and source arrows/attachments. Shared navy/gold row frames and live typography differ in engraving, density and proportions. |
| Unread indicators | Raised native red/gold dots and counts, tied to local example read state. These are not backend counts. |
| Letter panels | Original frames with cleared writing areas. Donor paper and bounded border repairs approximate the obscured original; faint tiling/smoothing may remain. |
| Letter content | Source-inspired live Russian/English text, explicit examples; delivery timestamps and expiry promises omitted. Guild attachment quantities follow the opened-letter example. |
| Claim / footer | Original green frame, compose/envelope/trash art; Back reused from approved navigation. Button captions are live. All transactions remain unavailable and explain why. |
| Scenery | Reused clean dark forest plate, not the original warm village/castle arrangement. |
| Typography | User-selected embedded fonts; exact source identity unknown. Size/weight and line wrapping differ. |
| Detail layout | Same Mail title, full parchment, sender/body/attachments/claim. Shared inbox footer retained; original detail-only expiry strip is omitted. |
