# Inventory baseline assessment

The original reference is preserved at `Reference.png` (the dedicated original from InventoryStyleAlignment/R1). Baseline01 re-ran the existing native Inventory tests before source changes.

Observed differences: the older header uses a different portrait and simplified resource surrounds; the background lacks the reference's carved wood; tabs and body text are heavier; the generic outer grid enclosure and selection surface differ; footer medallions are oversized; the page is vertically centered on tall screens. Existing20 item cards, title and feather detail retain source artwork, but hidden quantity-removal areas remain approximate. Reference quantities and collectible functions are examples, not currently owned items.

This pass targets shared navigation, edge placement, selection presentation, shared booster art/quantities and native text spacing. It reuses the approved existing resource family without image edits or new generation. Original carved enclosure, quantity plaque and hidden-surface refinements remain future reference-fidelity work.
