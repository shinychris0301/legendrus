# Profile R2 — relic frame, heading ornaments and captions

Compare the actual Unity captures with `../R1/Sources/Reference.png` using the review selector. This pass is a bounded refinement of the approved R1 Profile composition.

- The lower collection/detail region now has the original dark carved enclosure. Its corners use sprite borders so they retain their proportions on taller phones and on the expanded Relics tab.
- Original gold flourishes flank the hero and relic headings. Their navy backing is removed; the gold source pixels are retained.
- “Design preview” remains visible as a separate localized line below each collection heading, keeping the main title close to the reference's hierarchy.
- Relic captions use measured one-line sizing with inner clearance instead of wrapping across card decoration.
- Existing shared header, real-stat panels, hero/relic artwork, boosters and footer remain.

The hidden panel face uses a clean source navy donor; its texture is reconstructed. Fine alpha edges and the lower frame/detail junction are approximate. Long live captions may be smaller than the source lettering. Exact font identity remains unverified. The reference's hero XP, combat attributes, relic levels and upgrade controls are still intentionally replaced by saved game statistics and labelled previews under the earlier user approval.

The original footer is a continuous strip; R1 still uses three separate wooden faces. Detailed relic information is also adapted for the preview state. These remain the next useful visual refinements; no collection ownership or upgrades should be invented.
