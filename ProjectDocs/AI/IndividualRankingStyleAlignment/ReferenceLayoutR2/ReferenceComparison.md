# Original reference comparison — R2

Detailed follow-up: [R2 fidelity audit](QA/ReferenceFidelityReview.md) identifies residual title lettering, damaged frame masks and cut portrait edges. R2 is not an exact match; these are visible defects, not merely minor stylistic differences.

Compared the941×1672 original with actual Unity R2 captures, including the final Russian portrait. R1 used a legacy preview; it is no longer the visual authority.

| Area | R2 result | Remaining difference |

| Header | Existing approved native header, wallet and level bindings retained | Portrait/material details differ; no invented XP bar fill; live balances differ from sample values |
| Scenery | Scenario-generated clean dark birch forest | Hidden original scenery cannot be recovered exactly; placement and lighting differ |

| Service-dependent content | Explicit preview label; truthful season note and Rules explanation | Deliberately replaces the reference’s example countdown; no functioning leaderboard or prize grants yet |

Production uses isolated sprites and reconstructed blank opaque surfaces with separate live text. The original full reference is only a review source. No reference screenshot is used as runtime UI. Extraction quality is limited by overlap and the small source resolution; magnification adds no original detail.
