# Team Ranking R1 — reference comparison

Compared the original 941×1672 Guild Ranking reference, isolated assets and actual Unity captures. R1 follows the original composition; it is not an exact replica or an acceptance claim.

| Element | Implemented | Remaining difference |
|---|---|---|
| Russian title | Original lettering, shading and plaque, Scenario alpha isolation | Alpha edges are estimated; neighboring header fragments removed |
| Podium | Original gold eagle, silver wolf and bronze tree panels, original fixed 1/2/3 numerals | Old dynamic labels and reward groups cleared locally; their repaired faces differ from the original texture |
| Guild rows | Seven original emblems; original rainbow, gem and chest icons; live member/contribution/reward counts | Reused shaded row/reward frames, live rank numerals and labels differ in shape/weight; several names wrap |
| Player highlight | Sapphire row and gold rim | Explicit example plaque added; this is not confirmed guild membership |
| Details action | Original emerald/gold button, preserved aspect and live RU/EN text | Original caption removed with bounded local inpaint; live lettering differs |
| Header and scenery | Existing accepted account controls and clean dark forest plate | Original abstract navy plate, portrait details, XP bar and footer banners not reproduced exactly |
| Type | User-selected Roboto Serif600 for body/names, FreeSerif Bold for English heading, Bitter600 for live ranks | Exact source typefaces remain unknown; Russian fixed title uses original pixels |
| Filters and season | Local/Global and Week/Season selection with explicit sample state | All filters show the same examples; no live service or invented countdown |

Final Russian 941×1672, English safe576×1280 and English details overlay manually inspected. Other final captures have automated layout/glyph/raycast checks. Transparency inspected over black, white and magenta. Early English column overflow and details-button texture seam were corrected before the final run.
