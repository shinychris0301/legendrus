The current implementation has **no active broad background-darkening overlay**. `ProductionHomeRuntime.cs:48` and `:112` explicitly set `LowerShade.color = Color.clear`; the active prefab confirms alpha zero. `ProductionHomeShade.cs:15–24` multiplies its gradient by that color, making it invisible. Dark native HUD/card/quest backings are local panel surfaces, not a scene vignette.

The historical shade must not simply be switched back on. It sits above the combined Ivan/Firebird art and below the controls; its old stops reach alpha 224/255 and 255/255 over the lower 690 reference pixels, extending on tall screens. That would heavily wash out the accepted flame tail. The existing Edit Mode assertion at `HomeAlignmentDeliveryEditModeTests.cs:267` deliberately protects against this. A background-only correction needs its own placement and restrained tuning while retaining that protection.

No global UI brightness boost was found. Sprite-bearing Images in the active prefab have white tint and default materials. Button color multipliers are 1, with hover/pressed states that darken. The custom R8 material belongs only to the live Play label. The character's bottom fade modifies alpha, not RGB. The 26 Home PNG import profiles consistently enable sRGB and disable linear/gamma overrides; PNG headers contain no conflicting color-profile/gamma chunks. Existing project color-space settings were not changed. The R8 review HTML applies no brightness/contrast filter. These findings point to painted material values and compositing differences, rather than a new global exposure correction.

The page remains built from a clean environment, isolated visual assets, live text, local panel backings and twelve actual controls through the existing Home route and owner. This review found no reason to replace the accepted composition or startup architecture. The previous passing layout, input, loading and language checks remain historical validation; they were not rerun for this assessment. Exact source-font identity and physical-phone rendering remain unverified.

Recommended next focused implementation: **lower-background tone and Map-side foliage layering**, followed by selective gold/blue material balancing if still needed. Preserve all accepted artwork/geometry, R7 badges, R8 lettering, GUIDs and existing services. Do not reapply Splash's historical ColorFix06, alter rendering settings, or enable the old foreground wash.
