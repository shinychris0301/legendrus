# Parchment comparison

Confirmed cause: a small mirrored source sample was repeated over large cleared rectangles. This changed the parchment pattern and created light/dark bands. The new interior uses a continuous reference-guided texture with its mean color adjusted using original untouched parchment samples.

The title, outer silhouette, alpha and divider remain from the existing art. Both locales share the same parchment repair; the page still uses native text and interactive controls. The original scenery, logo variant and heavier body fonts remain different from the reference as previously documented.

This fix targets the panel interior, not the city scenery behind it. The repaired grain is approximate because the reference hides parts of the parchment under text and objects. It should not be described as an exact source extraction.
