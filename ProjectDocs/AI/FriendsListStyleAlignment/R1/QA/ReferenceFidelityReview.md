# Friends List R1 — reference comparison

Compared both original sources with actual Unity Friends/Requests/Find captures. The main reference hierarchy and original title, portrait faces, level badges, energy/visit shapes, request check/cross controls, gift boxes and five footer icons are represented as separate UI elements. This is not an exact whole-image match.

| Area | Implemented / remaining difference |
|---|---|
| Title | Original Russian lettering and plaque; English uses live selected typeface over a locally cleared face. Some smoothing/streaking remains in the English blank surface. |
| Account header | Approved shared header and real saved values; portrait/frame proportions and type weight differ from these originals. |
| Scenery | Existing clean dark forest plate reused. It differs from the original warm village and request-page scenery. |
| Rows | Native shared gold/navy frames; original portrait artwork. Row ornamentation, emblem designs and spacing are approximations. Source overlapping frame edges constrain some portrait tips, notably Merlin. |
| Tabs / search | Friends and Requests follow the originals. Third tab uses Find from the request reference, while the roster original says Invite. Search is a live local-example filter, added below the tabs. |
| Counts / statuses | Explicit example counts and status labels replace potentially misleading capacity/live-presence claims. Source level badges remain fixed examples. |
| Footer | Source-derived complete icon controls with live captions. Letter clearing smooths some plaque texture; Events retains its original illustrative exclamation badge. Footer typography is fitted to the actual caption faces. |
| Request gifts/actions | Original gift/check/cross art preserved. Requests are examples; actions explain unavailable online behavior and grant nothing. |
| Fonts | User-selected embedded Cyrillic-capable fonts; exact original identity still unknown. Original fixed Russian title retained. |
| Phone scale | Safe-area composition fits simulated narrow/tall displays. Small guild/status/footer text and touch comfort still need a physical-phone review. |

No source artwork was regenerated. Alpha isolation is estimated and enlarging low-resolution source elements does not recover missing detail. Black/white/magenta sheets are asset diagnostics, not the implemented page. Use the standalone HTML's actual Unity captures to assess composition.
