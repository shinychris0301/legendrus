# Team Hub R4 reference comparison

The source blue/gold guild crest and red motto plaque replace the navy footer treatment. Russian motto lettering comes directly from the original; English remains live/localizable. The original information symbol is now a separate working native button. Source alpha was checked against black/white/magenta; hidden red surfaces were repaired using clean source lacquer.

Footer composition intentionally differs: plaque/crest are uniformly scaled to80% to preserve separate Back and Friends controls. The source does not include those controls here. Navigation and decorative group follow the bottom safe edge, so tall screens retain extra scenery above them. Existing carved backing is reused rather than replacing the entire footer with a screenshot crop.

Remaining differences include the outer roster/footer scrollwork, selected live font weight/embossing, reconstructed row/plaque textures and portrait caps, scenery, and season-progress lighting. Shared approved header/gem/potion assets and saved balances are intentional adaptations. Guild membership, task counts/rewards and roster values are still labelled examples.
