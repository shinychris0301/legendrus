# Victory reference comparison — R1

Inspected `Assets/LegendsOfRus/Art/ReferenceOnly/ApprovedScreens/Victory.png` and the current native Unity portraits. Reference provenance marks the historic Loading material separately; the old handoff stops at Splash/Loading and does not describe the later accepted pages in CurrentTask. Current local page/runtime state takes precedence.

The reference establishes a three-resource header, raised-wing Firebird over dark Slavic scenery, burgundy Victory ribbon, three stars, rewards and emerald Continue above an amber video action. R1 uses those elements with independent sprites, live text and native buttons. It shares the current Pre-Level village plate/tint and Home header/Continue material; these are not the exact reference city's scenery or ornamental silhouettes. Generated Firebird/ribbon/amber control are independent interpretations, not pixel-identical reference extractions. Runtime stars are faceted native geometry with a short reveal; no confetti loop is added.

The reference's sample balances, three earned stars, 5,000 coins,20 gems and egg are not actual current game rewards. The new page displays the round's actual score and stars, actual first-clear currencies and awarded boosters; replays display zero first-clear rewards. Two to five reward cards are exercised by current authored levels (capacity six). Existing verified video reward doubles gold only. The label states coins explicitly. No egg reward or unavailable provider is invented.

Existing Cyrillic serif assignments are reused with live RU/EN UI labels. The exact source font remains unknown. Story reactions use the existing StoryService; authored reactions can fall back to Russian under English. That content limitation is preserved, not presented as newly translated dialogue.

Initial Unity review found overlarge sliced reward borders and labels too near their trim. Changed only Victory card rendering/proportions and moved labels inside the wood. Added a distinct generated amber video control. Final visual review and exact checks are recorded in ImplementationReport.md. New user visual acceptance is pending.
