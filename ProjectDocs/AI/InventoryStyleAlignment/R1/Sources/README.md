# Inventory source workflow

OriginalReference.png is the unchanged dedicated Inventory reference. It is review evidence only. Assessment.json records25 individual extraction bounds. InitialPreparation.py records the first preparation; do not rerun it over submitted evidence. ScenarioRequests.py calls model_pixa-background-removal through the existing Scenario helper, using exclusive submission markers. Never resubmit an accepted job to recover a download.

Scenario supplied alpha for the title,20 framed item cards, framed feather detail, parchment detail panel and two action buttons. Intentionally opaque panel/card illustration interiors retain their original surfaces. Existing approved clean environment, native account header, shop navigation graphics and four working booster artworks are reused without editing those files. One bounded paper-surface generation follows the failed local cleanup; other source illustrations are not regenerated.

Submitted Inputs/name.png files remain immutable. The intermediate RefineNativeInputs.py edits only native RGB and explicit masks: gold quantity glyphs are locally cleared; parchment writing is inpainted and the hidden button area uses a mirrored original clean-paper strip from [313,1151,341,1360]. Source use/details lettering is cleared for live localization. PrepareFinal.py applies Scenario alpha, retains the largest exterior component, restores opaque faces/frame interiors and produces an English blank-title derivative. Original RGB outside repair masks is verified before interpolation. Runtime sprites are3× resampled source resolution; this adds no source detail.

item_1's first PNG was truncated and retained as RejectedTruncatedDownload.bin. The download helper refused to overwrite a different file; after archiving the incomplete file, its existing job was recollected successfully. No additional generation or paid request was made.

Local parchment clearing was rejected after visible ghost letters and a stronger threshold damaged texture. ScenarioPaperRepair.py submitted one13CU repair. ApplyPaperRepair.py composites only its interior through a bounded seven-pixel feather mask, retaining original outer-frame RGB. Run this after RefineNativeInputs.py and before PrepareFinal.py.

Remaining limitations: reconstructed text/quantity areas, generated replacement parchment texture, fine alpha edges and reused shared ornaments are approximations. Items are preview art, not proof of owned artifacts or a functioning crafting system.
