# Pause R1 reference comparison

Authority: `Assets/LegendsOfRus/Art/ReferenceOnly/ApprovedScreens/Pause.png` (941 × 1672), explicitly approved in the historical Step11.2A reference closure. The Splash/Loading provenance index does not describe this later page.

The original implementation still used the generic FIX01 rounded frame, simplified vector-like boosters and sans-serif labels. R1 replaces those with an isolated source frame, ornate title, green Resume, blue Restart/Settings and red Exit controls, and four compact source booster cards. Russian title and action lettering retain original source RGB. Five Scenario background-removal outputs supply alpha masks only; no generated replacement color pixels are installed.

The source positions and native proportions define the central modal. Safe-area fitting keeps it uniformly scaled and centered on tall displays. Real goals support two or three slots with remaining amounts; stock counts are live. Booster cards show inventory without activating a booster while paused. Resume/restart/settings/exit stay on the established routes.

Differences remain: hidden panel surfaces and blank English controls required local source-texture reconstruction; some flattened silhouettes are interpreted at panel junctions. Headings, instructions, quantities and English labels use the existing local serif font, whose exact reference identity is unknown. The accepted current Gameplay scene, gems, HUD and footer remain behind the modal, so the background intentionally differs from the older Gameplay depicted in the Pause reference. Real level goals and inventory also differ from its sample values. Whole-page pixel identity is not claimed.

Runtime uses independent UI sprites, live text and native controls over live paused gameplay. Neither a full-screen reference nor scenery-contaminated screenshot rectangles are runtime UI.
