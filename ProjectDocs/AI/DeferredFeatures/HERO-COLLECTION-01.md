# HERO-COLLECTION-01 — Functional hero collection

Status: deferred design/feature definition after UI review. This record does not authorize a new economy or claim that ownership is implemented.

Visual Page36 Characters R1 uses Ivan as the current hero and provides local browsing of eight labelled source-character previews, with All/Rare/Legendary concept filters. Upgrade/Select are disabled. Combat attributes are em dashes. Existing saved currency/energy balances remain real. Profile already follows the same preview approach. No answer to the optional scope question was received before implementation; the conservative visual-only assumption was stated to the user.

Before functional implementation, define hero acquisition/ownership, persistent selected hero, stat and rarity rules, upgrades and prices, abilities/booster relationship, and the actual effect on gameplay. Then implement save migration, valid ownership/selection, atomic spending, unavailable states and tests for reload/refund/duplicate input. Do not grant preview characters, inferred stars, skills or rewards as real inventory. Keep localization and safe-area layouts. Coordinate Profile and Characters only after rules are agreed.
