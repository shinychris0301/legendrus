# Settings reference fidelity — rebuild R1

Compared the dedicated original Settings image with the native baseline and rebuilt Unity captures. The overall parchment, four preference rows, six service rows, original Russian title, carved enclosure and blue Back medallion follow the original arrangement.

## Improvements

- The current Home header is now an actual shared component, including energy and the approved portrait/resource treatment.
- Navigation follows phone safe edges. The central panels retain their composition; nine-sliced outer rails let the bottom arch follow Back on taller displays.
- Live label/value spacing better respects the original icons, toggle faces and arrow controls.
- Approved ornamental separators replace plain lines. Sign Out's second text line now reports its unavailable status honestly.
- Consistent native press feedback applies to settings rows, switches, header and modal controls.

## Differences still visible

The live type remains heavier than the reference; exact source-font identity is unverified. Row and parchment textures use earlier bounded repairs, so their grain differs. The dividers are approved Mail artwork, not exact Settings-source separators. The approved Home environment is coherent with the rest of the rebuilt game but is not identical to the original Settings scenery. Tall screens intentionally add breathing room between the header and central title, and extend only the outer frame's middle rails.

Header values and preferences are real saved values. Cloud displays local-save status rather than unsupported Connected text. Account/sign-out/support/privacy remain constrained by existing implementations. Notification permission/delivery is not added. Language selection uses the existing modal and persisted/session mechanisms; no new localization service is introduced.

The language modal artwork is unchanged. This task does not claim whole-image parity. The next fidelity refinement should address the remaining row-face texture and live-type differences if needed; Language Select is the next page in sequence.
