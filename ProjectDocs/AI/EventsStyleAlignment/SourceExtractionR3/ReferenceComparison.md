# Events R3 — comparison with the original

Compared the original Events941×1672 design with the final actual Unity R3 Russian capture and tall English capture. R3 follows the approved extraction-first workflow. It improves source-art fidelity, while the page remains a native, localized implementation with truthful event states.

| Area | Applied | Remaining difference |
|---|---|---|
| Heading | Original plaque silhouette, crest and scrollwork isolated; live gold text retained | Hidden face under baked lettering was locally reconstructed. Exact font/embossing remains approximate. |
| Tabs | Original angular gold/navy tab isolated and reused consistently | Selected blue face remains native; the reference's Active badge is absent because there are no active events. |
| Card rails | Original source rails/corners, sliced for the unequal row heights; separate ornament overlay above scenery | Empty navy interior reconstructed using source texture. First two frames extend a source frame from the third row. |
| Status | Original clock from R2 plus original thin status strip | Pixa returned empty strip alpha; local source-silhouette restoration was required. Date-pending text replaces the illustrative countdown. |
| Action | Original green/gold action border, original aspect retained | Baked caption and shadow removed with a fitted green surface. Preview/Soon remain live, with different lengths from the reference captions. |
| Subjects | Original firebird, Baba Yaga/cauldron, merchant and knight/shield RGB; Scenario alpha with bounded cleanup | Flattened source limits clipped edge recovery. Firebird's broad background glow is reduced by isolation. Some edge softness remains at original source resolution. |
| Scenery | New separate clean plates behind each original subject; city reused behind heading | Hidden scenery is regenerated, not exactly recovered. Building placement, lighting and main full-page environment still differ. |
| Rewards | Original isolated icon examples, including separate recovered merchant chest/medal; explicit RU/EN example label | These are not confirmed prize recipes. Icons are smaller than the reference to fit the existing honest labels and controls. |
| Navigation/layout | Existing shared header, real balances, native Back and R2 unequal card layout preserved | Shared portrait, missing authoritative XP fraction, footer wording and last-card height differ. No fabricated progress or sample balances. |

No original full-screen screenshot or scenery-contaminated rectangular crop is used as runtime UI. UI surfaces intentionally remain opaque; subjects and rewards are separated from source scenery. Existing source/generated outputs and repair masks are retained. Original pixel equality is verified outside documented repair masks; this is not proof of exact whole-page color/rendering fidelity.
