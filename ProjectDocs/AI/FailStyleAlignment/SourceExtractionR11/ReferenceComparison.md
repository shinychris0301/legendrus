# Reference comparison — R11

The original button/card/medallion artwork now matches much more closely because it uses actual source pixels, not newly interpreted illustrations. All text, quantities and progression remain real UI data.

| Area | Implemented | Remaining difference |
|---|---|---|
| Title | Original crest, silhouette, gold edging and navy face; native proportions | Hidden lettering area is reconstructed. Live font/bevel differs from the baked reference font. |
| Retry | Original emerald face and frame; natural aspect | Blank face was repaired beneath the old caption; live glyphs differ. |
| Paid/ad cards | Original red/blue and green faces, engraving, corners and embedded symbols | Extra unavailable labels compress the live title layout; price is an unknown dash, not reference40. Cards are deliberately disabled pending feature integration. |
| Goals | Original thin frame and heading surface; actual goal icons/counts | Approved gameplay icon family and actual unfinished goals differ from screenshot samples. Heading is wider to accommodate live RU/EN states. |
| Boosters | Original hammer, phoenix, shield and potion medallions; original dimensional badges with live stock | Source numbers were repaired; cropped overlap at the bottom is covered by separate nameplates. Row is lower to retain the usable chapter-map action and guide. English captions may wrap. |
| Main panel | Existing geometry retained; darker neutral tone; simplified inset/booster borders | R10 outer scrollwork and lower crest still differ from the source. |
| Ivan/scenery | Retained independent Scenario R10 resources | Pose, face/hair edge lighting, cloak embroidery, fire/building positions remain approximate. |
| Header | Prior functional header retained | Portrait, progress rail and some ornamentation remain approximate. Saved resource values/level intentionally differ from screenshot examples; unimplemented experience displays a dash. |

No pixel-perfect whole-page claim. Source RGB preservation outside repair masks does not mean hidden pixels or final rendered typography were recovered exactly. Original controls were separated into genuine sprites; the flattened reference is never a runtime page.

Visual comparisons used the original941×1672 reference and actual Unity captures. Native-frame and source-pixel checks are quantitative; scene, typography and material assessments are visual, not calibrated measurements. User acceptance remains pending.
