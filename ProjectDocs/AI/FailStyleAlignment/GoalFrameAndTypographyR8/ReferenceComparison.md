# R8 reference comparison

The goal section now follows the reference hierarchy more closely: a narrow heading plaque crosses a subdued outer frame, with a separate inner goal inset. The original source sprites are reused whole. Angular corner shapes and plaque ends still differ from the reference's painted scroll details.

The heavier title face is closer to the reference's bold gold lettering. The plaque dimensions remain unchanged. Its typeface is the existing local serif font, not an identified exact match. Goal heading and availability text are bolder; booster labels have higher contrast without changing names or condensing letters.

The accepted main panel, character, background and R7 offer/booster geometry remain. Red/blue offer face proportions and decorative details still differ. Availability labels and the unknown-price dash deliberately represent deferred continuation functionality. Real goal types, counts, currency and stock remain data-driven.

The result is a focused framing/type refinement, not a pixel-identical reference reproduction. Check the single-portrait selector in the review page for R8, R7 and original reference views. All implementation images are actual Unity captures with simulated displays/safe areas; they are not physical-phone screenshots.
