# Legends of Rus v1.6 — Runtime Flow

Open in Unity 6000.5.9f1.

Before Play:
1. Ensure Input System package is resolved as 1.20.0.
2. Active Input Handling = Input System Package (New).
3. Dynamic Batching = Off.
4. Run `Legends of Rus > Validate Commercial Vertical Slice`.
5. Open `Assets/Scenes/Bootstrap.unity`.
6. Press Play.

This build implements the first commercial vertical-slice loop, not only static mockups.
